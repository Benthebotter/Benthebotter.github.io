# CryptoSpins - Modernes Crypto Casino

## Beschreibung
Eine moderne, vollständig responsive Crypto-Casino-Website mit No-Deposit-Bonus-Fokus. Entwickelt mit HTML5, CSS3 und Vanilla JavaScript.

## Features

- Modernes, responsives Design
- No-Deposit-Bonus Integration
- Crypto Payment Ready
- Mobile Optimized
- Provably Fair Games
- Schnelle Auszahlungen
- Interaktive Elemente
- Crypto-Preis-Ticker

## Technologien

- HTML5
- CSS3 (Flexbox/Grid)
- Vanilla JavaScript
- Responsive Design
- Modern Animations
- SVG Graphics

## Installation

1. Klonen Sie dieses Repository:
```bash
git clone https://github.com/dein-nutzer/crypto-casino.git
```

2. Öffnen Sie die `index.html`-Datei in Ihrem Browser

3. Für Live-Vorschau empfehlen wir Live Server Extension in VS Code

## Dateistruktur

```
crypto-casino-website/
├── index.html
├── styles.css
├── script.js
├── README.md
└── assets/
    └── (SVG Grafiken als Inline-Data)
```

## Anpassung

Um die Website an Ihre Bedürfnisse anzupassen:

1. Ändern Sie die Farben in `styles.css` unter `:root`
2. Passen Sie die Bonus-Informationen in `index.html` an
3. Ändern Sie die Spiele in der `games` Section
4. Aktualisieren Sie die Kontaktinformationen im Footer
